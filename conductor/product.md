# Product Definition: Boardgame Online Platform

## Project Purpose
The project aims to develop an online platform for playing board games, with a specific focus on implementing "TIME BOMB EVOLUTION". This platform will provide a digital environment for users to engage in board game sessions remotely.

## Technologies

### Frontend
-   **Framework:** React
-   **Language:** TypeScript
-   **Build Tool/Dev Server:** Vite (using rolldown-vite)
-   **Real-time Communication:** Socket.IO Client

### Backend
-   **Runtime:** Node.js
-   **Framework:** Express.js
-   **Real-time Communication:** Socket.IO

## Architecture
The project is structured as a monorepo, separating the frontend (`client/`) and backend (`server/`) components.

## Conventions
-   **Linting:** ESLint is used to maintain code quality and consistency.
-   **Typing:** TypeScript is utilized across the project for type safety and improved development experience.
