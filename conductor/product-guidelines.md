# Product Guidelines: Immersive & Thematic

## Tone and Voice
The platform's tone and voice should be **Immersive & Thematic**, aligning with the specific lore, narrative, and aesthetic of the board games hosted. This approach aims to create a rich, engaging, and consistent experience for players, drawing them deeper into the world of each game.

### Key Principles:
-   **Narrative Consistency:** All communication, from UI text to system messages, should reflect the thematic elements of the game being played.
-   **Atmospheric Language:** Use evocative language that enhances the game's atmosphere and lore.
-   **Visual & Audio Harmony:** Ensure that written content complements the visual design and soundscapes of the games.
-   **Character-Driven (where applicable):** If games feature distinct characters or factions, the platform's messaging can adopt their perspectives to enrich the player's immersion.
-   **Respect for Lore:** Maintain accuracy and respect for the established lore of each game, avoiding anachronisms or thematic inconsistencies.
-   **Engaging Descriptions:** Craft descriptions and prompts that pull players into the game's world, making interactions feel like part of the story.

## Language
All UI interface text, prompt messages, and code comments generated for this project shall uniformly use Traditional Chinese (繁體中文).
