# 矮人礦坑 2 實作說明

依據工作區 `SABOTEUR_2_IMPLEMENTATION_SPEC.md` 的數位規則加入既有平台，遊戲識別碼為 `saboteur-2`。沿用會員登入、朋友房、AI 補位、準備、重新開始及即時同步，沒有建立第二套應用程式。2026-09-23 已補部署正式資料庫的私人手牌規則；本次故障修補只發布資料庫規則，前端重複提示修正保留在工作區。

## 遊玩

大廳建立 2–12 人朋友房，或選 AI 練習，設定 1–11 位 AI、輕鬆／標準難度。推薦 5–8 人。全員準備後由房主開局。每場三輪；輪末先分金、依序處理偷竊，再由房主確認下一輪。第三輪偷竊完成後公開總分，同分共享勝利。

選道路會標示合法位置，可旋轉 180°，預覽後按「蓋路」。行動牌彈窗只列合法目標；雙工具修復需再選一種工具。換牌可選 1–3 張，解除自身狀態需棄 2 張、補 1 張。手牌、身份、情報、玩家詳情及結算均使用彈窗。受困、工具損壞與待偷竊直接顯示圖示。

棋盤支援滑鼠／觸控拖曳、雙指縮放、縮放按鈕、完整礦道、入口與目標定位。畫面固定在視窗內；長列表只在彈窗內捲動。每項公開操作依 revision 排隊播放約 3.2 秒提示，卡牌移動約 2.6 秒；AI 間隔至少 3.6 秒。重新連線不重播歷史操作。減少動態效果偏好保留文字提示。

角色視窗加入六種原創矮人插圖，以隊色、服裝及工具區別身份；確認揭牌前不掛載角色圖。道路卡增加岩壁、木門、橋板、梯子與水晶，行動卡各有礦洞場景。黃金、水晶使用彩色礦石插圖，玩家持牌量以疊放的小牌背配數字呈現。大廳使用專屬礦坑插畫，移除共用背景的 AVALON 字樣。

每輪結束（含第三輪）先顯示勝方揭曉視窗，播放 4.4 秒角色進場、光芒與礦石落下動畫，之後按「查看本輪結算」才顯示分金／總分。支援藍隊、綠隊、雙隊、破壞者及兩隊被色門阻擋的特殊身份結果；中止對局不播放勝利動畫。減少動態效果時顯示相同勝方與確認流程，不播放移動效果。這次美術與結算介面修改尚未發布 Hosting。

## 規則與資料

- 六種身份、15 張身份牌，每輪隨機發牌；未用身份供更換身份抽取。舊身份放回牌堆底，偵查歷史保留當時資訊。
- 每輪秘密移除 10 張、每人 6 張。原創功能牌組共 121 張：44 張基礎道路、27 張基礎行動、30 張擴充道路、20 張擴充行動。基礎道路形狀分布是本平台定義的可玩牌組，並非逐張重製商業版牌表；所有美術均為程式繪製 SVG／既有圖示。
- 以卡片內部通道建立連通圖。橋梁與雙彎道不會錯接；梯子重連入口，不能貼目標；已揭岩石可延伸。色門只影響隊伍通行與勝負，不影響一般鋪路連通判斷。
- 全部 11 種行動，含持續工具／陷阱／偷竊效果、落石、藏寶圖、偵查、更換身份、交換手牌。交換後由對方補牌；私人查看需確認後才換人。
- 黃金接通或全員手牌耗盡結算；依接通者身份與可通行隊伍判勝，工頭／奸商扣分、地質學家按場上水晶分金，受困者排除。偷竊依最近放置者起順時針執行，可偷先前輪次累積金塊。
- 暫時離線保留座位；明確離開會中止對局，避免留下無法行動的座位。此遊戲目前不納入既有勝場排行榜。

## AI 陣營與路線判斷

輕鬆與標準模式都先排除違反自己目標的行動，再決定策略優先度。破壞者會封住通往目標的出口、落石切斷有效道路，不會隨機鋪路幫忙挖金或移除阻路牌；挖金矮人會拓展可達礦道、清除阻塞，並考慮自己的隊色色門。地質學家優先放置水晶。

路線評估使用與規則引擎相同的連通通道，包含橋梁、雙彎道、梯子及色門；不把靠近目標但未連通的道路視為進展。對其他玩家只採用自己的有效偵查與公開蓋路、修復、破壞紀錄推測立場。換身分後捨棄舊判斷；未知身份不會被直接當成盟友修復或當成敵人攻擊，藍綠挖金隊仍會合作對抗破壞者。

`tests/saboteur-bots.test.ts` 覆蓋兩難度的蓋路、阻路、落石、敵友目標、過期情報、隊色與水晶偏好；既有完整模擬另驗證 2／5／12 人三輪對局與私人資訊隔離。

2026-09-25 已更新正式 `advanceBots`（`asia-east1`）。全平台 508 項單元測試與建置通過；現有房間之後的 AI 行動會使用新策略，不需重開對局。

## 同步與保密

`sessions/{code}/public/saboteur` 僅放棋盤、效果、手牌張數、行動紀錄與階段。`saboteurPrivate/{uid}` 保存本人身份、手牌、累積金塊及私人情報，資料庫規則限定房內本人讀取。牌堆、移除牌、未用身份、目標答案留在伺服器 `secret/saboteur`，用戶端不可讀寫。

所有行動由 callable transaction 驗證座位、階段、手牌、目標與 `gameId:revision`，同版本重複提交最多成功一次。Firebase 省略空陣列／物件時會先正規化。AI 策略只收到公開狀態與自己的私人狀態，無法得知其他身份、手牌、未看過的目標或未來抽牌；不需要外部 AI API key。

主要程式：`functions/src/saboteur/`（規則、計分、AI），`functions/src/shared/saboteur.ts`（資料與牌組），`mineTopology.ts`（通道），`mineActions.ts`（合法目標），`client/src/games/saboteur/`（棋盤、卡牌、彈窗與動畫）。

## 驗證

若開局顯示「私人資料暫時無法讀取」，且公開房間仍可讀，請確認部署包含 `database.rules.json` 的 `saboteurPrivate/{uid}` 規則。只發布 Hosting／Functions 會留下舊權限；正式環境曾因此拒絕合法玩家的手牌訂閱。可使用 `npx firebase deploy --only database --project boardgame-online-platfor-c5ebd` 補發布，玩家重新整理或按「重新載入私人資料」即可恢復。不要以公開私人資料分支的方式處理。

`tests/browser/room-permissions.spec.ts` 會重現缺少規則、重新整理仍失敗、補回規則後原座位恢復手牌與出牌，並檢查只出現一份錯誤提示與重試按鈕。

```sh
npm test
npm run lint
npm run build
# 另一終端先啟動 npm run emulators，確認函式已載入
node tests/saboteur-integration.mjs
npx playwright test tests/browser/saboteur.spec.ts
```
