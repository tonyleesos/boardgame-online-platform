# 教父風雲：危情古巴

依 `MAFIA_DE_CUBA_IMPLEMENTATION_SPEC.md` 實作於現有平台，遊戲 ID 為 `mafia-de-cuba`。

## 支援玩法

- 6–12 位玩家，可加入 AI，沿用會員登入、朋友房、單人練習、準備、房主交接與再開一局。
- 房主指定或隨機教父；15 顆鑽石、依人數配角色籌碼及寬恕酒瓶。
- 教父秘密藏起 0–5 顆；第一位可秘密移除一枚角色，再選擇拿取；最後一位可空手離開。
- 收到空盒時，由伺服器判定為街頭小子，玩家按鈕確認傳盒。空盒不自動跳過座位，所有人維持相同公開傳盒流程。
- 追查竊賊、寬恕無辜者、探員獨勝、最高存活竊賊同分勝利、街頭小子及司機連鎖勝利。
- 清道夫選項預設關閉，啟用時取代一名忠誠手下。每次指控固定保留 8 秒，不論清道夫是否被拿取、移除、出局或是否已選擇；未回應視為放行。
- 原始入座順序固定；畫面順時針下一位是右手邊，最後一位連回第 1 位；出局不改變司機對象。

依使用者後續要求，已擴充原規格未包含的 AI 練習：單人可搭配 5–11 名 AI，選自己或 AI 擔任教父，也可在朋友房加入 AI。策略函式只接收公開狀態及該 AI 自己的私人資訊，沒有全體角色或秘密移除資料；教父採不確定的座位先驗與隨機指控，適合規則練習，不模擬真人語音推理。清道夫 AI 選擇不更新公開活動、時間戳或 `moved` 回應。

未加入 5 人專家版、Revolución、觀戰、語音或推理助手。`config.expansion` 保留 `NONE` 擴充入口，目前拒絕其他值。

## 資料與時序

`sessions/{code}/public/mafia` 只包含公開回合、持盒者、座位、指控、已揭曉角色及終局資訊。伺服器真實盒子、藏鑽、秘密移除及完整角色資料位於 `secret/mafia`，客戶端無讀寫權限。

`mafiaPrivate/{uid}` 只允許本人讀取。傳盒交易同時刪除舊持有人 `currentBoxView`，交付下一位最新盒子；不保留歷史快照。盒子回到教父後才提供剩餘盒子與失竊統計。正常終局清除私人盒子並公開全部身分；明確離席中止本局時只清除盒子，不公開未完成的秘密。

真人操作經既有 `gameAction`，AI 由 `advanceBots` 呼叫同一規則引擎，皆使用完整 Session transaction；`gameId:revision` 拒絕舊分頁、重複點擊與重開局前的請求。清道夫選擇不更新公開 revision，避免洩漏擁有者或選擇；私有選擇旗標防止重送。

指控使用伺服器截止時間：基本版 1.5 秒，清道夫版 8 秒。在線成員定期請求結算，伺服器驗證時間及版本；同時請求只會有一次成功。全部人離線時停留該階段，重連後自動結算。瀏覽器時間僅控制顯示，不決定合法性。

暫時離線保留座位，禁止遊戲中清理成 AI；明確離開中止本局，由留在房間的房主重新開局。

## 圖像與動畫

原創美術與生成提示記錄於 `client/public/art/mafia-art.md`。公共畫面只播放相同的關盒傳遞；私人拿取完成後才播放鑽石或角色入袋。結算依次展示藏鑽、移除籌碼及各玩家角色，提供略過演出；支援系統減少動態效果。

## 驗證

```sh
npx vitest run tests/mafia.test.ts
# Auth、RTDB、Firestore、Functions 模擬器執行中
node tests/mafia-integration.mjs
npx playwright test tests/browser/mafia.spec.ts
npm run lint
npm run build
```

模擬器測試以 6 人與 12 人驗證完整流程、跨玩家／教父越權、歷史盒子刪除、重新讀取、同時拿取、重開局版本隔離、結算及清道夫私有回應。瀏覽器測試使用實際模擬器與兩個獨立登入瀏覽器，檢查桌機、390px 手機、私人入袋與公開畫面隔離、重整及終局演出。
