# 犯人在跳舞

遊戲代碼：`criminal-dance`。大廳可建立 3–8 人朋友房，或由 2–7 位 AI 補滿單人練習。沿用平台電子郵件／密碼登入、房號、準備、重連與重新開局。

## 已完成

- 基礎 32 張牌、依人數保留必要牌後隨機補牌、每人 4 張；未使用牌不公開。
- 第一發現者強制先行，犯人必須最後出牌，犯人持有者從當前手牌判定。
- 共犯亮牌後生效；偵探以出牌前張數判定效果；不在場證明不被消耗，偵探失敗只公開相同的「不是犯人」。
- 目擊者私人確認視窗；查看內容只提供給出牌者，確認後刪除，公開紀錄不包含情報牌面。
- 神犬由伺服器隨機抽牌、翻牌棄置；未抓到犯人時將神犬交給目標。依文件的「一位玩家」允許選擇仍有手牌的自己；不能抽空手玩家。
- 情報交換：所有有牌玩家秘密鎖定，最後一人完成時一次移牌。交易：雙方選好後一起交換。謠言：從效果前快照抽牌後同時移動。不會再次轉傳本次剛收到的牌；空手者仍可收到牌。
- 回合略過空手玩家，收到牌後重新參與。房主選擇 5／10 分目標，預設 3–5 人為 5 分、6–8 人為 10 分。最高總分勝出，同分並列。
- 犯人逃脫時犯人與亮牌共犯各得 2 分，不重複計分。被抓時犯人與共犯都得 0 分；其餘破案者偵探得 2 分／神犬得 3 分，其他人得 1 分。共犯即使親自抓到犯人仍按同陣營敗北計分，遵循文件第 15 節。
- 少年選配：替換一張目擊者，初始持有者取得一次性的開局犯人情報，換手後不更新。
- 警部選配：預設關閉，啟用後替換神犬，與少年獨立設定。公開標示目前持有人，交易／情報交換／謠言完成時同步更新；其他手牌仍保密。出牌前手牌超過 3 張不可使用，出牌後公開指定另一位玩家、固定目標，到本輪結束才判定。
- 警部終局判定：在結束動作清理手牌前保存私有快照；若目標是最後犯人且沒有不在場證明，`resolution = POLICE_CHIEF` 優先覆蓋原偵探／神犬／逃脫計分，警部得 3 分、犯人與亮牌共犯 0 分、其餘玩家 1 分。沿用基礎版陣營優先規則，若警部玩家本身也是犯人或亮牌共犯，仍為 0 分。動畫先揭曉警部攔截，再顯示得分。
- 原創 SVG 卡牌插圖、牌背、小手牌堆與共犯／選牌圖示。點手牌放大後確認，避免直接誤出牌。
- 手機、平板、桌機與橫向布局；主要桌面及手牌同頁可見，規則、紀錄、私人情報與目標選擇使用彈窗。較長的彈窗內容可捲動。
- 每次行動約 3.2 秒動畫／訊息，移牌使用牌背，神犬顯示翻出的公開牌與移交神犬；AI 行動間隔至少 3.6 秒。畫面播放未完時，該用戶的確認操作暫停。減少動態效果偏好下保留閱讀時間及結果文字。
- 每輪先以插圖動畫揭曉逃脫／破案，再開啟分數；房主確認後開始下一輪。短暫離線保留資料，明確離席則中止本場並交接房主。

## 實作位置

| 路徑 | 用途 |
| --- | --- |
| `functions/src/shared/criminalDance.ts` | 卡牌、公開／私人型別、合法出牌、目標與共用時序 |
| `functions/src/criminalDance/engine.ts` | 配牌、狀態機、原子移牌與計分 |
| `functions/src/criminalDance/bot.ts` | 限定資訊的 AI，含輕鬆／標準選項 |
| `functions/src/criminalDance/expansions/policeChief.ts` | 私有終局快照與警部判定 |
| `client/src/games/criminalDance/` | 桌面、卡牌、彈窗與動畫佇列 |
| `database.rules.json` | `dancePrivate/{uid}` 僅限房內本人讀取；所有遊戲寫入由伺服器處理 |

公開資料位於 `sessions/{code}/public/dance`；手牌、秘密選擇、目擊者與少年情報位於 `dancePrivate/{uid}`；未發牌、交換快照與整體秘密選擇位於 `secret/dance`。禁止直接讀取私人根節點、別人的私人分支及整個 secret。

所有行動帶 `gameId:roundId:revision`，在同一 RTDB 交易驗證及提交。並行鎖定遇到版本改變時需依最新畫面再送出，不會覆寫先前玩家的選擇。八人局沒有未發牌，能處理 Firebase 省略整個空 secret 分支的情況。

AI 僅接收公開狀態、自己的手牌與合法取得的個人情報，交換後清除可能過時的目擊者記憶。由在線真人客戶端推進；所有真人關閉頁面時暫停，重連後繼續。

## 範圍

依使用者要求納入 AI 練習及較慢動畫，覆蓋文件原先「MVP 不含 AI」及較短動畫的建議。警部已依更新後 Addendum 的數位規則開放。此遊戲的累積分數與勝利在房內顯示，未擴充平台永久勝場排行榜。
